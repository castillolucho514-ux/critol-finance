# Contributing / Contribuir

Thank you for improving Critol Finance. Open an issue before substantial work, keep pull requests focused, and include tests for behavior changes.

Gracias por mejorar Critol Finance. Abre un issue antes de trabajo sustancial, mantén los pull requests enfocados e incluye pruebas para cambios de comportamiento.

## Development / Desarrollo

```bash
npm install
npm run dev
npm run dev:api
```

Use environment variables for credentials; never commit `.env` files. This project is licensed under Apache-2.0.
